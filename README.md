## 📱 تثبيت الموقع كتطبيق (PWA + APK)

### أولاً: العمل بدون إنترنت (PWA)

الموقع مجهّز تلقائيًا للعمل بدون اتصال بعد الزيارة الأولى عبر
`sw.js` + `manifest.json`. يكفي رفعه على GitHub Pages وفتحه مرة واحدة.

### ثانيًا: التثبيت كتطبيق على الجهاز

- على **Android/Chrome**: تظهر رسالة "تثبيت التطبيق" أو استخدم
  زر **📲 تثبيت كتطبيق** في شاشة الدخول أو الإعدادات.
- على **iOS/Safari**: زر المشاركة ← "إضافة إلى الشاشة الرئيسية".
- على **Desktop/Chrome**: أيقونة التثبيت في شريط العناوين.

### ثالثًا: بناء ملف APK (لتوزيعه أو تثبيته من الموقع)

الأسهل هو **PWABuilder**:

1. ارفع الموقع على GitHub Pages وتأكد أنه يعمل.
2. ادخل إلى <https://www.pwabuilder.com/>.
3. أدخل رابط موقعك (`https://<username>.github.io/<repo>/`).
4. اختر **Android → Generate Package**.
5. نزّل الملف `*.apk` (وقد ترغب في ضبط `Package ID` واسم التطبيق).
6. أعد تسمية الملف إلى `statistics.apk` وضعه في **جذر المشروع**
   (بجانب `index.html`).
7. ارفعه إلى GitHub Pages — سيصبح زر **⬇ تنزيل APK** يعمل مباشرة
   من الموقع.

بديل: **Bubblewrap** من Google
(<https://github.com/GoogleChromeLabs/bubblewrap>).

> ⚠️ ملاحظة: ملف APK المبني عبر PWABuilder أو Bubblewrap هو في
> الحقيقة **TWA (Trusted Web Activity)** — تطبيق غلاف يفتح موقعك
> بدون شريط عناوين. هذا يعني أن التطبيق يحتاج إنترنت **مرة واحدة**
> على الأقل لتثبيت ملفاته الداخلية، ثم يعمل بفضل Service Worker
> الذي جهّزناه. للعمل بدون إنترنت كليًّا من أول ثانية، ستحتاج
> لحزم الموقع بالكامل داخل APK (مثل Cordova/Capacitor) — لكن ذلك
> ليس ضروريًا في حالة STATISTICS لأن Service Worker يكفي.
