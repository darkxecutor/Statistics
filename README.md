# STATISTICS — لوحة إحصائيات الإنجاز

موقع ويب عربي (RTL) لمتابعة المهام والأهداف اليومية والأسبوعية والشهرية،
بهوية بصرية سوداء/ذهبية، ومخططات بيانية، ونظام مكافآت.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | الهيكل العام: شاشة الدخول + التطبيق |
| `css/style.css` | كل الأنماط والهوية البصرية والتأثيرات |
| `js/storage.js` | إدارة البيانات، الحفظ التلقائي، حسابات الإحصائيات |
| `js/audio.js` | محرك الصوت المُولَّد (كسر الكتابة + صوت الأزرار) |
| `js/effects.js` | الشظايا + الموجة + ربط الحقول `.type-crack` |
| `js/charts.js` | تغليف Chart.js للمخططات العمودية والدائرية |
| `js/auth.js` | تهيئة Google Sign-In والجلسة |
| `js/app.js` | منطق التطبيق والواجهات والأحداث |
